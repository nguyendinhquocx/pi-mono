## Lessons (chạy tiếp vào runbook)

1. Test fixture pin version cứng (`baseVersion: "1.3.0"`) vỡ khi VERSION tăng — derive từ `VERSION` config.
2. `vi.waitFor` default 1s quá chặt cho replacement pipeline Windows (1.2–3.4s) — set timeout tường minh cho flow nhiều bước.
3. Runbook snapshot script truyền `sys.argv` string vào `json.dump` → receipt counts là string — fix int cast trong script gốc.
4. `test.sh` preview-packages: Git Bash GNU tar nuốt Windows drive path; Windows-native tar + `npm_execpath` chạy được 10/10.
5. Full-suite Windows có ~7-10 timeout/EBUSY flakes không correlate code — gate thật sự là isolated target suites + Li suites.
